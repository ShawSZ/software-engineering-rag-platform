# Synthetic B03 fixtures

These files are original synthetic testing material created for this project and dedicated to the public domain under CC0-1.0. They contain no personal data or third-party course documents.

- `course.pdf`: two text pages about requirements and testing; expected page numbers 1 and 2.
- `course.txt`: UTF-8 with BOM, repeated synthetic text for 800-code-point chunks with a 100-code-point overlap.

JUnit additionally generates image-only scanned pages, encrypted/corrupt PDFs, empty text and invalid UTF-8 in isolated test directories. No OCR or model service is needed.
